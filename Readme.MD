Each project is designed with interview scenarios in mind, showcasing different aspects of JavaScript programming, from DOM manipulation to API integration and modern web development practices.

## 🛠️ Projects

### 1. 🌤️ Modern Weather App

**Tech Stack:** Vanilla JavaScript, Tailwind CSS, OpenWeatherMap API

A sophisticated weather application featuring glassmorphism design and real-time weather data.

**Key Features:**

- Real-time weather data integration
- Modern glassmorphism UI design
- Responsive across all devices
- Smooth animations and transitions
- Error handling and validation
- Geolocation support

### 3. 🎲 Drag & Drop List App

**Tech Stack:** Vanilla JavaScript, HTML5, CSS3 (Flexbox)

An interactive drag-and-drop application where users can move list items between two containers.  
This project demonstrates DOM manipulation, drag events, and responsive design techniques.

**Features:**

- Drag & drop between two containers
- Glassmorphism-inspired UI design
- Responsive layout with flexbox and media queries
- Visual feedback on drop targets
- Smooth animations and transitions
